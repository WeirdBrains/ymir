\section{Backwards compatibility}\label{sec:compat}

Ymir is built to let old and new pieces run side by side, so a pool can be upgraded one machine
at a time and existing tools keep working. The rule is that every protocol carries its version in
its name, and a new version is served next to the old one rather than replacing it.

\code{catalog/1}, \code{sync/2}, \code{task/1}, \code{coord/1}, \code{control/1} & Versioned names; a future version is meant to be served alongside, as with infer \\
Weirdnet profile & Ymir and Bragi copy the standard Weirdnet profile and change only their link scheme, so certificates verify and all apps share one network \\
Shared sync group & Needs Morph v0.3 or later on every device; the Morph 0.2 line cannot join, so devices move together \\
OpenAI bridge & Existing tools use standard \code{/v1} endpoints unchanged; Ymir-specific signals ride in extra headers they can ignore \\
MCP & Speaks MCP 2026-07-28 and still answers older initialize requests \\
Stock engines & A node can wrap an already running \code{vllm serve} or \code{llama-server} instead of replacing it \\
Updates & Self-update refuses downgrades and rolls back to the last good release after two failed starts \\
